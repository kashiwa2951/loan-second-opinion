# 奨学金 返還セカンドオピニオン

JASSO奨学金の返し方を、**そのまま／減額返還／返還期限猶予／繰上返還／延滞した場合**の5つで
並べて比べられる無料のWebページです。ダウンロード不要、会員登録不要、広告なし。

入力した内容はすべてブラウザの中だけで計算され、どこにも送信されません。
銀行口座やJASSOのアカウントと連携する仕組みは持っていません。

👉 **https://kashiwa2951.github.io/loan-second-opinion/**

---

## なぜ作ったか

JASSOの「令和5年度 奨学金の返還者に関する属性調査」に、こういう数字があります。

| | 無延滞者 | 延滞者 |
|---|---|---|
| 返還義務があることを申込手続きの**前**に知っていた | 88.5% | 54.4% |

さらに、**延滞している人の54.4%は返還期限猶予制度を、42.3%は減額返還制度を「延滞督促を受けてから」初めて知った**と回答しています。
延滞理由の第1位は「本人の低所得」で64.5%。延滞者の67.2%が年収300万円以下です。

つまり延滞の主な原因は無知でも怠慢でもなく低所得で、それに対する救済制度は**すでに用意されている**。
足りていないのは、制度と当事者をつなぐ導線だけです。

そして決定的な事実があります。

> 減額返還は、毎月返還する割賦金を減額して、返還期間を延長するものです。**返還予定総額が減額されるわけではありません**
> **第二種奨学金の利子の総支払額は変更ありません**
> — [JASSO 減額返還制度の概要](https://www.jasso.go.jp/shogakukin/henkan_konnan/gengaku/seido.html)

減額返還は**追加コストがゼロ**です。月々が下がって期間が延びるだけで、総額も利息も増えません。
いっぽう延滞すると、延滞金（年3%）に加えて3か月で個人信用情報機関に登録され、
督促に応じなければ返還期日が来ていない分まで一括請求されます（期限の利益の喪失）。

しかも**減額返還は「願出及び審査の時点で延滞していないこと」が条件**です。延滞してからでは使えません。

「延滞するくらいなら減額返還を申請すべき」——これを、あなた自身の数字で確かめられるようにしたのがこのページです。

## 計算の正確さ

JASSOが公開している[割賦金基礎額表](https://www.jasso.go.jp/shogakukin/henkan/houhou/henkan_hoshiki/henkan_kikan/index.html)にもとづき、
`返還年数 = floor(貸与総額 ÷ 割賦金基礎額)`（最長20年）で返還回数を算出しています。

検証は、JASSO公式の[「大学・返還例」](https://www.jasso.go.jp/shogakukin/henkan/houhou/henkan_hoshiki/kappu/sample/daigaku.html)に
掲載されている **58件（第一種10件・第二種48件）** を正解データとして行っています。

| | 結果 |
|---|---|
| 第一種の返還回数・返還月額 | **全件で完全一致** |
| 第二種の返還回数 | **全件で完全一致** |
| 第二種の返還月額 | 最大誤差 **1円** |
| 第二種の返還総額 | 最大誤差 **51円**（相対 0.00051%） |

第二種に誤差が残るのは、貸与終了から返還開始までの据置期間の利息の扱いをJASSOが公開していないためです。
公式返還例48件に対して較正した値（据置5.89か月相当）を `DEFERMENT_MONTHS` として持っており、
`test/calc.test.mjs` が全件の誤差を常に監視しています。

減額返還の延長月数は「適用月数 ×（1 − 減額割合）」で概算しています。
実際の返還期間はJASSOの承認内容で決まります。

```bash
node --test test/calc.test.mjs
```

## ローカルで動かす

依存パッケージはありません。Node.js があれば動きます。

```bash
node tools/serve.mjs
```

`http://localhost:5173` が開きます。
`index.html` を `file://` で直接開くとESモジュールがCORSで読めないので、このサーバーを使ってください。

## 制度が変わったときの更新

数値はすべて [`assets/jasso-data.js`](assets/jasso-data.js) に集めてあります。
コードには一切ハードコードしていないので、このファイルだけを直せば追随できます。

更新が必要になるのは主に次の2つです。

**1. 第二種の利率** — 毎月決定されます。`RATES_2SHU` を更新し、`DATA_CHECKED_ON` の日付も変えてください。
出典は[第二種奨学金の利子と利率の算定方法](https://www.jasso.go.jp/shogakukin/about/taiyo/taiyo_2shu/riritsu_santei.html)。

**2. 制度の要件** — 減額返還は2024年4月に改正され、割合に「3分の2」「4分の1」が追加され、
給与所得者の収入基準が325万円以下から400万円以下に引き上げられました。今後も変わりえます。
`GENGAKU` `YUYO` `ENTAI` を更新してください。

`DATA_CHECKED_ON` はページのフッターに表示されます。**必ず一緒に更新してください。**
いつ時点の情報かが読み手に見えていることが、このツールの信頼の中身です。

## 設計上の約束

- **お金を取らない。** 広告もアフィリエイトリンクも入れません。金融商品や法律事務所への送客もしません。リンク先は公的機関だけです。
- **口座情報を預からない。** 銀行API連携（電子決済等代行業）もJASSOのスクレイピングもしません。すべて手入力です。
- **断定しない。** 計算結果と制度の一般的な説明だけを示します。「あなたは債務整理すべき」といった個別の法的助言は行いません（弁護士法72条）。判断は本人、相談先は公的窓口へ。
- **出典を隠さない。** すべての数値に出典URLと確認日を付けています。
